
# Patient Monitoring System

A Java Spring Boot project for managing patient details and recording vital signs.

## Features
- Register, view, edit, and delete patients
- Add patient vital readings
- Display latest vital signs and status
- View vital reading history
- Search registered patients

## Technologies
- Java
- Spring Boot
- MySQL
- Spring Data JPA
- HTML, CSS, JavaScript
- Maven

## How to Run
1. Install Java and MySQL.
2. Create a database named patient_monitoring.
3. Configure your local application.properties with your MySQL credentials.
4. Run: mvnw.cmd spring-boot:run
5. Open http://localhost:8080 in your browser.

Vital readings are manually entered sample data for demonstration.
This is an educational project, not a medical device.
